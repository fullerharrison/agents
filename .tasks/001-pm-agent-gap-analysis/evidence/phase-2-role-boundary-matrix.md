# Phase 2 Role Boundary Matrix

| Role ID | Role | Must Do | Must Not Do | Inputs Owned | Outputs Owned | Escalation Path | Evidence Source |
|---|---|---|---|---|---|---|---|
| BAS-ROLE-001 | Conductor | Coordinate lifecycle, enforce checkpoints, and maintain task-state progression. | Research code deeply, edit implementation files directly, or skip pause points. | User intent, task status in .tasks, phase workflow state. | Delegation prompts, checkpoint decisions, phase-state transitions. | Delegate to Explorer for research and Builder for implementation. | BAS-SRC-001, BAS-SRC-010 |
| BAS-ROLE-002 | Explorer | Perform read-only research and save plans in .tasks artifacts. | Modify files outside .tasks or invoke Builder without user direction. | Codebase observations, task context, phase needs. | task.md and phase-N plan markdown files. | Return to Conductor or user with saved plan output. | BAS-SRC-002 |
| BAS-ROLE-003 | Builder | Execute approved plans, run verification, and update phase progress. | Commit/push code or bypass verification evidence. | Reviewed plan, changed source files, test tooling results. | Implemented changes, verification outputs, updated task phase status. | Hand off to Reviewer for independent validation. | BAS-SRC-003 |
| BAS-ROLE-004 | Reviewer | Validate behavior with tests/checks and report pass or needs-work with evidence. | Declare pass without command output or skip functional verification. | Built artifacts and phase verification requirements. | Review findings and disposition status for checkpoint decisions. | Return to Builder for fixes or Conductor for checkpoint handling. | BAS-SRC-004 |
| BAS-ROLE-005 | Business Analyst | Produce requirements artifacts and hand off planning work when requested. | Bypass project context docs or skip required output locations. | Product scope, domain requirements, roadmap and architecture context. | PRDs, feature requirements, and handoff-ready requirement packages. | Handoff to Scrum Master for sprint/implementation planning. | BAS-SRC-005 |
| BAS-ROLE-006 | Scrum Master | Produce sprint and implementation plans with dependency-aware structure. | Execute code implementation directly when plan creation is the active scope. | BA requirements and roadmap constraints. | Plan artifacts and Builder handoff package. | Handoff to Builder using Implement Phase after plan save. | BAS-SRC-006, BAS-SRC-007 |
