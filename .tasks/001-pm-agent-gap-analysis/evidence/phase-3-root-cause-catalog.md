# Phase 3 Root-Cause Catalog

All seven mandatory root-cause category codes are accounted for below. Categories confirmed as observed have at least one RC-* entry. Categories confirmed absent are marked `NOT-OBSERVED` with rationale.

| RC ID | Root-Cause Category | Description | Affected Artifacts in VIP Environment | Baseline Contract ID(s) Violated | Evidence Source(s) | Remediation Priority |
|---|---|---|---|---|---|---|
| RC-001 | `PATH-RESOLUTION` | Binary-file conversion tooling path in the VIP environment lacks a working executable or environment-variable binding to complete `.make`-format-to-readable conversion. The write path from the binary input to the learning-base target path is broken at the tooling layer, not the instruction layer; the agent correctly attempted the conversion but the underlying tool invocation failed and no fallback path was defined. | ART-002 (ingestion chat export with binary-handoff error at L2090, L32082); ART-003 (L32614: binary conversion attempt) | BAS-CONTRACT-002; BAS-MEM-004 | FAIL-001; ART-002:L2090; ART-002:L32082; ART-003:L32614 | Phase4-Critical |
| RC-002 | `GATE-MISSING` | VIP agent orchestration does not enforce the Conductor mandatory-checkpoint sequence at task initialization, mid-flow dependency failures, phase-transition boundaries, or result-communication handoffs. Specifically: the Task Created gate (BAS-GATE-001), the Plan Review Complete gate (BAS-GATE-002), and the Implementation Start gate (BAS-GATE-003) are absent from or bypassed in the VIP workflow, allowing the flow to advance or delegate without explicit user decision capture. | ART-001 (VIP task.md agent config defining orchestration behavior); ART-003 (session showing direct delegation without visible checkpoint pause) | BAS-CONTRACT-001; BAS-CONTRACT-004; BAS-CONTRACT-010; BAS-GATE-001; BAS-GATE-002; BAS-GATE-003 | FAIL-001; FAIL-002; ART-001; ART-003:L32702; ART-006 | Phase4-Critical |
| RC-003 | `CONFIG-DRIFT` | VIP PM agent instruction content does not include the BAS-SCHEMA-003 recommendation block emission requirement. The baseline instruction set requires that when risk-governance context is detected (unresolved blockers, stakeholder alignment risk, governance uncertainty), the agent emits a structured recommendation block; this obligation is absent from the VIP instruction configuration, causing the agent to produce status-only responses where the baseline would produce an actionable recommendation block. | ART-001 (VIP agent configuration); ART-008 (response evidence showing status-only output without recommendation block) | BAS-CONTRACT-010; BAS-SCHEMA-003 | FAIL-003; ART-008; ART-003:L33091 | Phase4-High |
| RC-004 | `TRIGGER-MISSING` | Two trigger conditions present in the baseline are absent from the VIP environment: (1) the BA-to-planning-intent trigger equivalent to BAS-TRIG-006, which should cause the BA agent to route planning requests through the explicit Scrum Master handoff channel rather than delegating async; (2) a risk/governance-context trigger that activates PM recommendation block generation when qualifying signals are present. Both trigger predicates are unimplemented, causing the VIP agents to fall through to generic delegation or status responses. | ART-001 (VIP agent configuration); ART-003 (chat log showing trigger conditions not firing) | BAS-CONTRACT-008; BAS-TRIG-006; BAS-SCHEMA-003 | FAIL-002; FAIL-003; REPRO-002; REPRO-003; ART-008; ART-002:L4706-L4814 | Phase4-High |
| RC-005 | `FORMAT-CONTRACT` | VIP BA and Scrum Master agent outputs do not conform to the BAS-SCHEMA-001 planner-ready project plan or BAS-SCHEMA-002 planner-ready issue checklist required field structures. The required sections (hierarchy graph, sprint planning template, risk assessment, milestone list, issue breakdown with labels/milestones/DoD, priority matrix, dependency map, board configuration guidance) are absent from the captured planning output artifacts. Additionally, BAS-SCHEMA-004 BA requirement output package obligations (save-target alignment, acceptance-level requirement detail) are not satisfied. | ART-007 (planning handoff evidence; schema fields absent); ART-004 (target Planner workbook format anchor); ART-003 (planning request-response block at request_5ab36e44) | BAS-SCHEMA-001; BAS-SCHEMA-002; BAS-SCHEMA-004; BAS-CONTRACT-008; BAS-CONTRACT-009 | FAIL-002; REPRO-002; ART-003:L32702; ART-007 | Phase4-Critical |
| RC-006 | `ROLE-BOUNDARY` | VIP orchestration delegated the planning task directly to a background agent execution path before completing the Conductor checkpoint sequence and before routing through the explicit BA→Scrum Master→Builder handoff chain required by BAS-ROLE-005 and BAS-ROLE-006. The BA agent did not invoke the Plan Sprint handoff channel to Scrum Master; the Scrum Master role did not produce or save a plan artifact; the transition to Builder-equivalent execution occurred without an approved plan path. | ART-003 (session delegation evidence showing background agent invocation); ART-007 (absence of Scrum Master handoff artifact) | BAS-CONTRACT-003; BAS-CONTRACT-005; BAS-ROLE-005; BAS-ROLE-006 | FAIL-002; ART-003:L32702; ART-007; ART-006 | Phase4-High |
| RC-007 | `PM-TOOL-LOGIC` | VIP PM agent layer has no implemented logic to evaluate qualifying context conditions (presence of unresolved blockers, stakeholder alignment risk signal, governance uncertainty indicator) and select an applicable PM framework tool for recommendation. The baseline PM recommendation obligation — implemented via BAS-SCHEMA-003 — requires active context evaluation before each response completion; this evaluation loop is entirely absent from the VIP agent, producing status-export responses regardless of how many qualifying signals are present in context. | ART-001 (VIP agent configuration); ART-008 (response evidence without recommendation block) | BAS-SCHEMA-003; BAS-CONTRACT-010 | FAIL-003; REPRO-003; ART-008; ART-003:L33091; ART-002:L4706-L4814 | Phase4-High |
