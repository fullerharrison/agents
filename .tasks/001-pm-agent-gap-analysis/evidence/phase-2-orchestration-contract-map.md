# Phase 2 Orchestration Contract Map

| Contract ID | Initiator Role | Target Role | Trigger | Required Inputs | Required Outputs | Failure Signal | Evidence Source |
|---|---|---|---|---|---|---|---|
| BAS-CONTRACT-001 | User | Conductor | Any new request under orchestrated mode; Conductor entry gate runs before response. | User request context and access to .tasks state. | Resolved task context and selected workflow branch. | Any response before .tasks state resolution breaks entry-gate contract. | BAS-SRC-001 (entry gate + first action protocol), BAS-SRC-010 |
| BAS-CONTRACT-002 | Conductor | Explorer | Step 1 task initialization and phase planning stages. | Task prompt, task slug, existing task status if present. | .tasks/[NNN]-[slug]/task.md with phase table and planned unit metadata. | Missing task artifact or skipped phase planning checkpoint. | BAS-SRC-001 (Step 1, Step 2a), BAS-SRC-002 |
| BAS-CONTRACT-003 | Conductor | Explorer (phase-review mode) | A plan exists and reaches plan-review checkpoint. | Phase plan file path and current phase index. | Review findings and approval status returned to checkpoint. | Plan advanced without phase-review evidence. | BAS-SRC-001 (Step 2a.2 + checkpoint rules) |
| BAS-CONTRACT-004 | Conductor | Worker | Phase approved and execution starts; state transition to in-progress required. | task.md path and selected phase number. | Phase status transition from reviewed to in-progress. | Execution starts with stale status state. | BAS-SRC-001 (status transition guidance) |
| BAS-CONTRACT-005 | Conductor | Builder | Implementation step starts for approved/in-progress phase. | Phase plan path and reviewed implementation intent. | Code or artifact changes plus verification status summary. | Builder invoked without plan path or with unreviewed phase. | BAS-SRC-001 (Step 2c.1), BAS-SRC-003 |
| BAS-CONTRACT-006 | Builder | Reviewer | Implementation complete and quality verification requested. | Changed files and applicable verification commands. | Test/type/lint/functional verification evidence and disposition. | Completion claimed without verification output. | BAS-SRC-003, BAS-SRC-004 |
| BAS-CONTRACT-007 | Reviewer | Conductor | Review result returned to orchestration flow. | Review findings with status pass or needs-work or fail. | Checkpoint decision options and next action branch. | Auto-advance without checkpoint approval. | BAS-SRC-001 (Implementation Complete checkpoint), BAS-SRC-004 |
| BAS-CONTRACT-008 | Business Analyst | Scrum Master | BA uses sprint planning handoff trigger (Plan Sprint). | Requirements artifacts and scope constraints. | Sprint or implementation plan artifacts aligned to plan locations. | BA output without downstream planning handoff despite planning request. | BAS-SRC-005 (handoff label + prompt), BAS-SRC-006 |
| BAS-CONTRACT-009 | Scrum Master | Builder | Plan ready for engineering and Implement Phase handoff invoked. | Saved plan file and execution-ready scope. | Builder execution of plan and implementation output. | Plan not saved or no explicit implementation handoff. | BAS-SRC-006 (Implement Phase handoff) |
| BAS-CONTRACT-010 | Conductor | User | Every mandatory checkpoint and final result communication. | Current phase status and checkpoint options. | Explicit pause with user decision controls before continuation. | Batched or skipped checkpoints reduce user control. | BAS-SRC-001 (mandatory pause points + unconditional checkpoints), BAS-SRC-011 |
